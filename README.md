# 🐍 NotebookLM - Estudos em Python

## 📖 Contexto e Objetivos

Este repositório documenta meu processo de aprendizagem em **Python**, utilizando o **NotebookLM** como ferramenta de apoio aos estudos.

O objetivo foi reunir diferentes fontes de conhecimento (artigos, documentações e materiais didáticos), centralizando as informações em um único ambiente para facilitar consultas, gerar resumos, esclarecer dúvidas e criar materiais de revisão através da Inteligência Artificial.

### Objetivos de estudo

- Compreender os fundamentos da linguagem Python;
- Aprender a sintaxe e as boas práticas de programação;
- Desenvolver lógica de programação utilizando Python;
- Conhecer estruturas de controle, funções e coleções;
- Criar uma base sólida para projetos futuros em desenvolvimento e Inteligência Artificial.
