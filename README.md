# 🐍 NotebookLM - Estudos em Python

## 📖 Contexto e Objetivos

Este repositório documenta meu processo de aprendizagem em **Python**, utilizando o **NotebookLM** como ferramenta de apoio aos estudos.

O objetivo foi reunir diferentes fontes de conhecimento (artigos, documentações e materiais didáticos), centralizando as informações em um único ambiente para facilitar consultas, gerar resumos, esclarecer dúvidas e criar materiais de revisão através da Inteligência Artificial.

### Objetivos de estudo

- Compreender os fundamentos da linguagem Python;
- Aprender a sintaxe e as boas práticas de programação;
- Desenvolver lógica de programação utilizando Python;
- Conhecer estruturas de controle, funções e coleções;
- Criar uma base sólida para projetos futuros em desenvolvimento e Inteligência Artificial.

Com esse exemplo da calculadora, foi aprendido quatro pilares fundamentais da programação:

A estrutura elif: gerenciar múltiplas opções de escolha (como as quatro operações) de forma organizada, evitando vários ifs isolados
.
Comparação de Textos: Usar o operador de igualdade (==) para verificar se o símbolo digitado corresponde a uma operação específica
.
Reforço de Tipagem: Praticar a conversão de dados, garantindo que os números sejam tratados como float (decimais) para permitir divisões precisas
.
Fluxo de Exclusão: Entender que o else no final serve como uma "rede de segurança" para capturar entradas inválidas do usuário
.

⚠️ Dificuldades Encontradas (Troubleshooting)

Durante os testes percebi que alguns prompts geravam respostas muito genéricas.

Exemplo

❌

Explique Python.

Resposta superficial.

Depois reformulei para:

✅

Explique Python para alguém que conhece lógica de programação, utilizando exemplos práticos e comparando com JavaScript.

A resposta ficou muito mais completa.

Outro aprendizado importante foi dividir perguntas grandes em várias perguntas menores, obtendo respostas mais específicas.

📖 Glossário

Variável
Espaço utilizado para armazenar um valor.

Lista
Coleção ordenada e mutável.

Tupla
Coleção ordenada e imutável.

Dicionário
Coleção baseada em chave e valor.

Função
Bloco reutilizável de código.

Loop
Estrutura de repetição.

Indentação
Organização obrigatória do código em Python para definir blocos.

Módulo
Arquivo contendo funções e classes reutilizáveis.
